# Projeto de Boas Práticas de CSS com BEM

Este projeto utiliza a metodologia BEM para organizar a estrutura HTML e CSS. Os estilos foram escritos em SCSS e compilados para CSS.

## Estrutura
- `index.html`: HTML principal.
- `bem/`: Arquivos SCSS e CSS.
- `assets/images/`: Imagens do projeto.

## Como usar
1. Compile o SCSS:
   ```bash
   node-sass bem/main.scss bem/main.css
